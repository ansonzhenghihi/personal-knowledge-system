# 知识学习技能 (Knowledge Learner)

## 触发条件

当用户说以下内容时，**必须**使用此技能：

- "帮我学习《xxx》这本书"
- "学习《xxx》"
- "读《xxx》这本书"
- "帮我学习这篇文章：[链接/内容]"
- "学习 xxx 知识点"
- "创建概念/思想/场景/问题卡片"

## 知识库路径

**默认知识库根目录**：`F:\Personalknowledgesystem\knowledge`

```
knowledge/
├── MEMORY.md          # 全局索引（AI 记忆）
├── domains/           # 知识领域
├── books/             # 书籍卡片
├── concepts/          # 概念卡片
├── ideas/             # 核心思想卡片
├── scenarios/         # 应用场景卡片
└── problems/          # 解决问题卡片
```

## 一、书籍学习流程（6 步）

### 触发
用户说："帮我学习《书名》这本书"

### 执行步骤

#### Step 1: 创建学习记录
```
1. 在 knowledge/books/ 创建 {书名slug}.md
2. 写入基础元数据（书名、创建时间、状态：学习中）
3. 输出：✓ [步骤1] 创建学习记录
```

#### Step 2: 联网搜索作者信息
```
1. 使用 web_search 搜索"书名 作者 背景"
2. 提取：作者研究领域、学术成就、代表作
3. 更新书籍卡片的"作者简介"部分
4. 输出：✓ [步骤2] 获取作者信息
   - 作者：xxx
   - 背景：xxx
```

#### Step 3: 获取书籍基本信息
```
1. 如果用户提供内容 → 直接解析
2. 如果只有书名 → web_search 搜索书籍简介、目录
3. 提取：出版年份、内容简介、目录结构
4. 更新书籍卡片
5. 输出：✓ [步骤3] 获取书籍信息
   - 出版年份：xxx
   - 核心主题：xxx
```

#### Step 4: 提取知识结构
```
1. 从内容中识别核心概念
2. 提炼核心思想
3. 归纳应用场景
4. 总结解决问题

为每个提取的内容创建卡片：
- 概念 → knowledge/concepts/{概念slug}.md
- 思想 → knowledge/ideas/{思想slug}.md
- 场景 → knowledge/scenarios/{场景slug}.md
- 问题 → knowledge/problems/{问题slug}.md

输出：✓ [步骤4] 提取知识结构
   - 创建概念卡片：[[概念1]]、[[概念2]]
   - 创建思想卡片：[[思想1]]
   - 创建场景卡片：[[场景1]]
```

#### Step 5: 建立关联关系
```
1. 更新 knowledge/MEMORY.md 全局索引
2. 在书籍卡片中添加双向链接 [[概念]]、[[思想]]
3. 在各概念/思想卡片中添加来源 [[书籍]]
4. 更新各 index.md 索引文件
5. 输出：✓ [步骤5] 建立关联关系
```

#### Step 6: 学习完成报告
```
输出：
✓ [步骤6] 学习完成！

📊 学习总结：
- 书籍：《xxx》
- 作者：xxx
- 生成卡片：X 张概念、Y 张思想、Z 张场景

📁 创建的文件：
- books/{书名}.md
- concepts/{概念1}.md
- ideas/{思想1}.md

🔗 后续建议：
1. 深入学习「xxx」，可阅读《相关书籍》
2. 了解「xxx」的实际应用
```

## 二、文章学习流程

### 触发
用户说："帮我学习这篇文章：[链接/内容]"

### 执行步骤

1. **获取内容**：如果是链接，用 `web_fetch` 获取
2. **提取信息**：标题、作者、核心观点
3. **创建卡片**：
   - 如果文章有明确概念 → 创建概念卡片
   - 如果文章有方法论 → 创建场景卡片
4. **更新索引**：更新 MEMORY.md

---

## 三、知识点学习流程

### 触发
用户说："帮我学习 xxx 知识点" 或 "学习 xxx 概念"

### 执行步骤

1. **联网搜索**：用 `web_search` 搜索该知识点
2. **整理信息**：定义、解释、示例、应用
3. **创建概念卡片**：`knowledge/concepts/{知识点}.md`
4. **关联书籍**：如果有相关书籍，添加关联
5. **更新索引**：更新 MEMORY.md

## 四、卡片创建规则

### 文件命名规则

| 类型 | 命名规则 | 示例 |
|------|----------|------|
| 书籍 | {中文书名拼音或英文} | thinking-fast-and-slow.md |

使用 `[[卡片名]]` 格式建立关联：

```markdown

- [[认知偏差]]
- [[系统1与系统2]]
```

### 必须包含的元数据

每个卡片必须有：

```markdown

- **所属领域**：
- **来源**：[[书籍名]]
- **创建时间**：YYYY-MM-DD
```

## 七、重要提醒

### ⚠️ 执行前确认

当用户要求学习书籍时，如果书籍内容较多或需要购买，**先确认**：

```
《书名》这本书内容较多，我需要：
1. 你提供书籍内容（文字/图片）
2. 或者我只基于公开的简介、目录、书评来学习

你想选择哪种方式？
```

### ⚠️ 内容来源

- 用户直接提供内容 → 直接学习
- 只有书名 → 联网搜索公开信息学习
- 版权内容 → 仅使用公开摘要，不复制原文

### ⚠️ 学习深度

根据用户需求调整：

```
用户说"快速学习"→ 只提取核心概念
用户说"深入学习"→ 详细笔记 + 关联分析
用户没说 → 默认标准学习流程
```
